# Wang Lab Website

This site is based on `sbryngelson/academic-website-template` and has been adapted with content from `../personal-site`.

## Main Files

- Site identity and navigation: `_config.yml`
- Home page: `_pages/home.md`
- About page: `_pages/about.md`
- Research page: `_pages/research.md`
- Publications page: `_pages/publications.md`
- Team and recruiting: `_pages/team.md`, `_pages/join.md`
- Lab news: `_data/news.yml`, `_posts/`
- Images: `images/`, especially `images/research/`

## Run Locally

```bash
bundle install
bundle exec jekyll serve
```

Then open `http://127.0.0.1:4000`.

## Repository Setup

The template was cloned from `https://github.com/sbryngelson/academic-website-template`. After creating a GitHub fork or new repository, set that repository as the push remote before publishing.
